# Agnostic Box 3D Models

This folder contains the 3D model files for the Agnostic Box.

The source models were made with [FreeCAD](https://www.freecad.org/). The folder includes FreeCAD source files, STL files, and a 3MF file for 3D printing the mechanical parts.

It is recommended to 3D print the parts with PLA. Open the FreeCAD files if you need to inspect or modify the models, and use the STL or 3MF files for slicing and printing.
