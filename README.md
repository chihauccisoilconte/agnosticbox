# Agnostic Box

This repository contains the files necessary to make an Agnostic Box.

## Author

Created by [chihauccisoilconte](https://chihauccisoilconte.eu/).

## Contents

- `agnostic box instruction manual.pdf` - build and assembly documentation.
- `agnostic box PCB/` - KiCad PCB files, Gerber files, drill files, PCB exports, and related PCB assets.
- `agonstic box 3D models/` - FreeCAD source files and STL/3MF files for 3D-printed parts.
- `agnostic box 2d vectors/` - 2D vector files and sticker artwork.
- `agnostic box arduino nano esp32 code/` - Arduino Nano ESP32 sketches.
