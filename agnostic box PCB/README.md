# Agnostic Box PCB

This folder contains the PCB files for the Agnostic Box.

The PCB was made with [KiCad](https://www.kicad.org/), an open source electronics design suite. The folder includes KiCad project files, schematic and PCB layout files, Gerber files, drill files, board backups, graphics, footprints, and PCB export files.

Use the KiCad project files to inspect or modify the schematic and PCB layout. Use the Gerber and drill files when ordering or manufacturing the PCB.
