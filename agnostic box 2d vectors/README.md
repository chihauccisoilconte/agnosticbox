# Agnostic Box 2D Vectors

This folder contains 2D vector files and graphic assets for the Agnostic Box.

The 2D files were made with [Inkscape](https://inkscape.org/) and [FreeCAD](https://www.freecad.org/). The graphics can be laser engraved, or they can be printed as stickers.

Use the vector files as source artwork for editing, engraving, cutting, or sticker production.
